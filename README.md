- `Fali_Honutse_Resume.pdf` — downloadable resume

## Deploy on Vercel

1. Create a new public GitHub repo, for example `fali-honutse-portfolio`.
2. Upload everything in this ZIP (keep the folder structure).
3. In Vercel, Import Git Repository, select the repo, and Deploy.
   No build command or output directory is needed.
4. Check the new `.vercel.app` URL before updating LinkedIn.
   Keep the old site live until the new one is checked.
